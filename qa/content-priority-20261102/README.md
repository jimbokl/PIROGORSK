## Оставшаяся очередь сайта

1. **CNT-01:** следующие темы месячного плана по Калининградской области:
   проверка публичных первоисточников и обновление владельцев; не выпускать
   отдельные URL для повторов. Часть требует только исследования, часть —
   свежих меню, часов, адресов и данных конкретных мест.
2. **SEO-01:** завершить проверку неполных таблиц регионального спроса и
   аномалий Wordstat, уточнить интенты/владельцев. Пробелы не равны нулевому спросу.
3. **SEO-03/04, ANA-01:** новая сверка индексации, запросов и переходов по
   накопленным наблюдениям, затем изменения статей по реальным запросам.
   Публикация и IndexNow не доказывают индексацию Google или рост позиций.
4. **PERF-01 / QA-02:** реагировать на воспроизводимые ухудшения и новые
   дефекты; прошедшие проверки не объявляются постоянной полевой гарантией.
5. **CI-01, P2:** профилировать холодную сборку изображений и сократить
   время выпуска с сохранением проверок. Ускорение в этом спринте не выполнялось.

Отдельные зависимости: DOM-09 — недостающие сведения о составе/хранении;
MEDIA-01 — настоящие фотографии; TRUST-01 и оформление/статусы/подписка/
акции — факты запуска и операционные условия. Контакты и CRM пользователь
отложил. Эти пункты не закрываются вымышленными данными.
