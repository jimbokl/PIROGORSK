# События и воронка

31.10.2026. Источник реализации — src/scripts/analytics.ts и storefront.ts.
Названия действующего счётчика сохраняются, чтобы не раздвоить исторические серии.

| Понятие A4 | Действующее событие | Триггер |
| --- | --- | --- |
| view_item | product_view | Открыта отдельная страница SKU; id из серверного каталога, один раз на загрузку. |
| add_to_cart | catalog_add | Успешное атомарное добавление; qty — прирост, source различает карточку/набор/дополнение/калькулятор/любимую/ссылку/подборку. |
| remove_from_cart | catalog_remove | Уменьшение, удаление или замена состава; qty — фактически удалённое количество. |
| city_switch | city_select | Только явный выбор другого города; восстановление и синхронизация не считаются кликами. |
| modal_open | selection_open / order_form_open | Открыта подборка / форма. Разные ступени. |
| submit / submit_with_cart | order_submit | Только серверные ok:true, saved:true и совпавший requestId; дедупликация по requestId. Состав передаётся как массив SKU/вариант/qty/value. |
| slot_select | Пока отсутствует | Желаемая дата уже сохраняется; интервалы не предлагаются, ложное событие не посылается. EXP-04. |
| prepay_click | Пока отсутствует | Реальной предоплаты нет. DOM-14 отложен; событие не симулируется. |

Дополнительно: catalog_filter_apply, order_form_start, order_submit_error,
calculator_interact, calc_apply_set, guide_to_catalog_click.

Параметры только из allowlist: три города, ограниченные source/surface/filling,
SKU/вариант/количество/сумма, UUID сохранения, зарегистрированные пути статей.
Нет контактов, сырых поисковых запросов, содержимого формы или URL с подборкой.
qa=1 отключает аналитику и сохраняет исключение при навигации этой вкладки;
локальные/сторонние preview тоже исключены. Просмотр не сообщает персональную
форму и не дублирует pageview. Метрическая конфигурация целей в интерфейсе
счётчика/дашборд не подтверждены этим кодовым спринтом: отдельная приёмка ANA-01.
