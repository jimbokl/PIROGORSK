# Подготовленные UTM и явный pageview — 24.10.2026

Для будущих Telegram-размещений подготовлены две фиксированные комбинации `utm_source/medium/campaign/content`: `menu_a` и `calculator_b`. Тексты и точные ссылки — [TELEGRAM-TEST.md](../TELEGRAM-TEST.md).

Предыдущий модуль передавал адрес без query в недокументированном поле `init.url`, а реферер — в `init.referrer`. Новая реализация использует официальный `init({defer:true})`, затем один `hit(очищенный URL, {referer})`. Что фактически принимал сервер в предыдущем варианте, этим сравнением кода не установлено.

- 14 Node tests PASS: прежние 11 для калькулятора/IndexNow и 3 новых для аналитики.

- Тест выполняет транспилированный реальный `src/scripts/analytics.ts` в изолированной среде со spy `ym`: один init с `defer:true`, один hit, ни одной цели, один script; повторная инициализация не добавляет hit/script. Query/hash реферера удалены.
- Это тест формирования вызовов, не доказательство появления рекламных визитов в отчёте Яндекса. Сеть в Node-тесте не используется.

- Backend и отправка заявок не менялись; новые тестовые заявки не создавались. Условие `order_submit` после сохранения не менялось.
