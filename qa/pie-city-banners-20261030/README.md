# Баннеры пирогового города — 30.10.2026

Пользователь одобрил новый логотип и попросил продолжить пироговый город в баннерах главной, с imagegen и проверкой телефона/планшета.

## Сделано

- Встроенным imagegen созданы три самостоятельные иллюстрации по одобренному brand-v6: большой пироговый город, три острова для компании, вишнёвый квартал. Золотистая выпечка, балтийские домики и тёмно-синие волны продолжают логотип. У всех исходников1254×1254 настоящий прозрачный альфа-канал0–255. [Исходники и точные промпты](../../design/pie-city-banners-20261030/PROMPTS.md).
- Заменены все три сюжета существующего слайдера. Подписи, ссылки и кнопки остаются HTML. Вишнёвый слайд ведёт на существующую страницу `/pirogi/pirog-s-vishney/`, наборы — к `#nabory`, основной — в меню.
- Единые пропорции и `object-fit:contain` показывают весь город без обрезки. Фон ягодного слайда слегка розовый, наборов — светлый тёплый. Исправлен `min-width:auto` текстовой колонки, из-за которого заголовок заходил на рисунок при320px.
- Astro создаёт AVIF/WebP240/360/480/640/800 со `srcset`/`sizes`. Первый рисунок eager/high, два остальных lazy/low; при выборе слайда картинка сначала декодируется. На телефоне1x первый AVIF16.3KB, на desktop1x30.3KB. Полноразмерные PNG в браузер не передаются.
