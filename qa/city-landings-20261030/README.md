Три самостоятельных городских контекста; ассортимент, цены, доставка и статус запуска взяты из общих данных проекта.

## Изменения

- Основные страницы перенесены из `/dostavka/{city}/` в корень. Заголовки, metadata, категории, сценарии и вопросы различаются по городам. Self canonical, внутренние ссылки, sitemap и SEO-реестр согласованы.
- Старые адреса содержат мгновенный meta refresh, canonical и fallback-ссылку; JS сохраняет query/hash. Проверено сJS и безJS. HTTP200 статического GitHub Pages не выдаётся за серверный301.
- Прямые кнопки трёх товаров передают город и точный формат. Исправлен существовавший дефект: входящий параметр города игнорировался при добавлении конкретного товара. Новый browser-сценарий начинает с другого сохранённого города и проверяет переключение, вариант и отсутствие дубля.
