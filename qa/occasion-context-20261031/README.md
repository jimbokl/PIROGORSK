# SCN-01 · Повод между страницами

Опубликовано, 31.10.2026. Статья/сценарий/калькулятор → каталог → анонимная форма.
Действие: выбор товаров и подтверждённое сохранение интереса. `order_submit`
только после ответа с тем же requestId; реальные заказы и слоты не заявлены.
Текущий backend уже принимает закрытый context v1, миграция не нужна.

Автовыбор только по перечисленным опубликованным тематическим URL и известным
параметрам существующих CTA. Новый тематический вход заменяет только автоматический
повод; явный выбор посетителя, в том числе undecided, остаётся до конца вкладки.
Сохраняются только enum и источник entry/choice; URL, поисковый текст, контакты
не сохраняются. При запрете sessionStorage работает память текущего документа.
Дата и время не выводятся из текста страницы. Лента и все 153 SKU сохраняются.

## Границы результата
