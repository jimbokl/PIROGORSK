## Проверки

SVG audit v3: все три символа без замечаний, 100/100 по эвристике скрипта.
Надписи A/B/C: 90/98/98. У A предупреждение о двух углах 120.6° относится к исходной
контурной букве «И» Playfair, а не к несовпадению деталей знака. Информационные
замечания — точность координат и число точек в контурном тексте. Это не оценка
юридической чистоты или потребительского восприятия.

Просмотрены PNG трёх проходов, итоговая доска, размерная лестница, увеличенные пиксели,
зеркальные, перевёрнутые и белые версии. В шаблоне исходный чёрный знак на чёрном
фоне намеренно не виден: для тёмного фона нужна показанная рядом белая версия.
На 16px волна A теряет плавность, а надрезы B требуют оптической версии в финальном
комплекте; C наиболее простой. Мелкий слоган в итоговый компактный логотип не входит.

`inspect-concepts.mjs` проверил 12 сочетаний: три направления ×320/390/768/1280px.
Локальный собранный сайт использован через GET interception, замена логотипа только
в DOM тестового браузера. Ширина ограничена свободным местом и текущей высотой шапки.
Без наложений на меню/подборку, горизонтального overflow и роста шапки; ошибок
загрузки ресурсов и JavaScript нет. `context-results.json` содержит геометрию,
`screens/header-*.png` — снимки. Просмотрены A на всех ширинах и B/C на 390px.
Это примерки в локальной сборке, не production QA новой опубликованной версии.

При первой примерке фиксированная ширина увеличивала шапку на 390/1280px.
Добавлен расчёт ширины с учётом доступной высоты; повтор прошёл все 12 сочетаний.

## Воспроизведение

Из корня проекта, при установленном logo-design skill и зависимостях проекта:

```sh
uv run --with fonttools --with brotli --with uharfbuzz python design/brand-v5/build-concepts.py v3
python3 "$HOME/.codex/skills/logo-design/scripts/svg_audit.py" design/brand-v5/concept-a-v3.svg
```

HTML размерных проб создаётся `preview_sheet.py` для трёх символов каждого прохода
в `qa/brand-v5-20261030/preview-v1.html`, `preview-v2.html`, `preview-v3.html`.
Локальные HTML также содержат библиотечные примеры для исследования; в сохранённые
материалы проекта входят собственные концепции и снимки шапки.
После создания HTML и при существующей `site/`:

```sh
node qa/brand-v5-20261030/inspect-concepts.mjs
```

Следующий шаг: выбор A/B/C пользователем. Затем — финальная геометрия, цвет,
светлая/тёмная версии, горизонтальный/вертикальный логотип, версия для малого
размера, favicon, примеры на упаковке, краткое руководство и внедрение на сайт.
