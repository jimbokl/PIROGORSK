# Количество прямо в меню — 30.10.2026

Задача: посетитель выбирает сразу несколько экземпляров формата в карточке, видит сумму и добавляет их одним действием. Весь текущий ассортимент `/menu/`: обе линейки пекарен, идеи Пирогорска и дополнения.

- Общий счётчик `− / число / +`; прямой ввод с клавиатуры. Смена формата сохраняет количество и пересчитывает сумму. Под суммой — цена единицы.
- Кнопка добавляет выбранную партию, повторное нажатие добавляет ещё столько же. Подборка и счётчик шапки отражают точное количество.
- На телефоне цена/счётчик в одной строке, кнопка ниже во всю ширину; на широком экране — рядом. Управление от 44px, видимый focus; без JS счётчик скрыт, ссылка остаётся рабочей.
- В ссылке передаётся количество: новая вкладка и fallback при недоступном storage сохраняют выбор. Повторное открытие URL не удваивает количество. Используется прежний контракт подборки (до99 единиц одного варианта).
- Аналитика `catalog_add` передаёт количество партии и её сумму. API/каталог/цены/SEO не меняются.

Проверки: `npm run check`, build, 41 Node test, Worker typecheck/API/SQL, общий браузерный прогон. `verifyMenuQuantity` включён в CI browser fixtures; отдельно `verify-ui.mjs` проверяет320/390/768/1024/1280px, клавиатуру, три источника карточек, варианты, суммы, повторное добавление, границы, storage fallback, reload и отсутствие overflow/JS/HTTP ошибок. Production формы не отправляются.
