# Наборы и дополнения — 30.10.2026

Задача: на главной и в меню выбрать набор из текущих SKU, затем по желанию добавить морс, сладкий пирог и посуду. Изображения и интерфейс — текущий балтийский стиль. Позиции остаются редактируемыми, цена равна сумме SKU, доставка учитывается один раз. Это анонимный интерес перед запуском, без оплаты и подтверждённого наличия.

Три сочетания: ужин (мясной/сырный по 500 г), компания (мясной/рыбный/капустный по 1 кг), сытное и сладкое (куриное филе/творог и изюм а-ля Русс по 1,2 кг). Первые два — концепты Пирогорска. Цены 1280/3470/5350 ₽ предварительные.

Реализация: общий раздел главной и меню; в подборке добровольные дополнения. Морс — клюква/облепиха 500 мл или 1 л; сладкий пирог — яблоко с брусникой/вишня/творог с малиной по 500 г; посуда — 1/5/10 наборов. Уже выбранная категория скрывается и возвращается при удалении. Набор добавляется целиком с проверкой существующих лимитов подборки. Переход из меню и обновление страницы не увеличивают количество повторно; явное нажатие добавляет ещё один набор. Новые SKU, скидки и CRM не вводятся.
