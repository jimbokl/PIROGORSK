# Единые карточки — 29.10.2026

Запрос: выровнять иллюстрации, заголовки, варианты, цены и кнопки на главной и в каталоге.

Причины: рамка и отступы применялись только к исходным пирогам; иллюстрации поставщиков на главной имели другой aspect-ratio; переносы заголовков и вариантов занимали независимую высоту. Появление со сдвигом запускалось только у первых двух карточек. При добавлении менялась ширина кнопки.

Изменения: общий квадрат иллюстрации, оформление и CSS subgrid по строкам; полный текст длинных названий; одинаковая геометрия выбора формата и кнопок 116×44px. В мобильной карусели карточки делят строки. В меню поставщиков шесть общих строк, переключатели минимум 44px. Единое появление всей избранной строки и одинаковые hover/focus/press для иллюстраций, с сохранением reduced motion. Ассортимент, цены, формы и API сохранены.
