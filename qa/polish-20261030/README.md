# Полировка меню, товарных страниц и хабов · 30.10.2026

## Что изменено

- `/menu/`: один общий поиск по 153 позициям, компактная вводная, наборы после каталога, сведения о форматах под раскрытие. Навигация показывает текущий раздел и количество найденных позиций. Пустой поиск можно сбросить с возвратом фокуса.
- Все 153 товарные страницы: количество 1–99, пересчёт формата и суммы, сохранение на текущей странице, синхронизация морса/сладкого/посуды и шапки. При отказе browser storage работает существующая передача через URL. Лимиты подборки не обходятся.
- Текстовые ссылки на соседние товары заменены визуальными карточками с иллюстрациями, форматом и ценой. На телефоне доступна горизонтальная прокрутка с видимым продолжением.
- `/povody/`, `/about/`, `/partners/`: общая айдентика пирогового города. В хабе поводов сначала общие сценарии, затем городские; быстрые ссылки на города и две колонки на планшете.
- Исправлен скачок ленты при переходе к следующей пекарне: запоздалая вставка предыдущей партии сохраняет положение уже видимого следующего раздела.

153 позиции, адреса, SEO-владельцы и этап анонимной подборки до запуска сохранены. Использованы уже одобренные оригинальные иллюстрации.

## Проверка

`verify-polish.mjs` — 10 маршрутов × 5 ширин (320/390/768/1024/1280), один H1,
границы заголовков, отсутствие горизонтального скролла и JS/HTTP ошибок. 12 групп
сценариев: поиск/сброс/фокус, активный раздел, раскрытия, формат × количество,
морс, точное слияние подборки, перезагрузка, предел 99 без перезаписи,
рекомендации, storage fallback и no-JS.

`verify-feed-anchor.mjs` — отдельная регрессия: реальные клики после поиска,
переход к Holland, переключение «Тесто → Весь ассортимент» во время подгрузки
предыдущей пекарни; положение кнопок сохраняется с допуском 2 CSS px.

Локально: check/build (217 HTML), 41 Node-тест, Worker/API/SQL, семь SEO/artwork
валидаторов и registry strict PASS. Полный browser-прогон и публикация отражаются
в `STATE.md`; итоговые сведения о CI и production будут внесены после проверки.

Первый товар меню на 390 px: **2593 → 998 px**, на 768 px: **2402 → 1123 px**.
Это положение относительно начала страницы; измерения сохранены в baseline и
`local/results.json`. Проверка экрана — эмуляция Chromium, не физические устройства.

release manifest с отдельно скачанным CI Pages artifact. Формы в production
не отправляются: `qa=1` и локальное сохранение подборки.
