Задача пользователя: применить seozavod к Пирогорску и провести спринт; отдельно инициализировать CodeGraph. База main a427ff8, публичный runtime 5a24752.

## Проблема и результат

До изменения две первые статьи глобального списка о Зеленоградске попадали в рекомендации по 21 разу, включая материалы о других темах и городах. В 22 динамических статьях работал этот общий fallback. Теперь все 23 статьи получают две ручные рекомендации по теме и ранний переход к соответствующему расчёту или подборке. Пример: статья о порциях → форматы 500 г/1 кг и выбор пирогов на компанию; следующий шаг → /podbor/. Дизайн блока использует существующие цвета и шрифты, текст прямо указывает стадию подготовки запуска.

Существующая карта расширена с 36 до 67 владельцев URL без создания второго реестра. Числа спроса неизвестны, SERP не проверена. Карта — редакционная гипотеза, не доказательство частотности или отсутствия каннибализации. Историческая группа expansion-20261026 сохранена для её прежних проверок.

Цель guide_to_catalog_click теперь различает источник и назначение по разрешённым путям без параметров/фрагментов URL. Неизвестные и внешние адреса исключаются. Это позволит сравнивать переходы по статьям после появления реального трафика. Никаких новых заявок в production при проверке не создавалось.
