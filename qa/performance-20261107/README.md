  Exit 0 скрипта подтверждает сохранение результата, не успешный PSI-аудит.
  CrUX в этом запуске не прочитан. Свежий публичный результат остаётся
  задачей наблюдения PERF-01.

[Снимок версии](baseline.json) снят после начала CLI-серии; это не

release manifest и catalog SHA подтверждены.
