## Одинаковая проверка на macOS и Linux

Первый CI остановился на проверке ширины приглашения: обычная полоса
прокрутки занимает 15 px, но `innerWidth` включает её. При окне 320 px
доступная ширина документа 305 px, текстовая колонка 215 px; прежний порог
220 px ошибочно считал её сжатой. Это воспроизведено локально с
`--disable-features=OverlayScrollbar` ([метрики](scrollbar-diagnostic.json)).
Проверка сравнивает заголовок с фактической внутренней шириной карточки,
продолжает проверять переполнение и запускает Chrome с обычной полосой.
