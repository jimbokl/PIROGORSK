# Карточки меню по мобильному референсу — 30.10.2026

## Направление

- Задача: быстрее сравнивать пироги в непрерывной ленте и собирать подборку с телефона.
- Референс: мобильные карточки Машенькиных пирогов из двух снимков пользователя; изображение слева, содержание и действие справа.
- Характер: белый фон, тёмно-синий текст и действие, спокойная светлая подложка переключателя.
- Композиция: крупная иллюстрация без квадратной рамки, компактный счётчик под ней; справа название, описание, формат, цена и небольшая кнопка в одной строке.
- Типографика: Golos для компактных карточек ленты, отчётливая иерархия названия и цены без обрезки названий.
- Движение: прежний отклик иллюстрации и кнопок; без появления по скроллу, с reduced motion.
- Узнаваемость: авторские иллюстрации и палитра Пирогорска; прежние цены, форматы и подборка.

## Реализация

`MenuFeedItem.astro`, `SupplierCatalog.astro`, `menu.css`, `supplier-catalog.css`. Общая обёртка цены и CTA; без новой клиентской логики. На телефоне повторная подпись «Предварительно» скрыта внутри строки; общий статус цен остаётся в начале соответствующего раздела. При больших количествах длинная сумма может перенести CTA на следующую строку, сохраняя целые числа и доступность.
