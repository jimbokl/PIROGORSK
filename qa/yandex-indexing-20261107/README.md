## Технический контроль production

[Воспроизводимый probe](probe.py), [полный результат](live-probe.json), [Sitemap](sitemap.xml). Запуск: `python3 qa/yandex-indexing-20261107/probe.py` из корня репозитория.

Проверяются те же десять URL, что 4 ноября: HTTP 200, конечный URL без редиректа, единственный canonical на себя, отсутствие noindex в meta robots/yandex и X-Robots-Tag. Дополнительно robots.txt с разрешением обхода и canonical sitemap; карта из 279 уникальных URL, все десять в ней; release.json совпадает с локальным опубликованным артефактом.

User-Agent YandexBot используется с рабочей станции, не с IP Яндекса. Эти запросы проверяют доступность для данного UA и не доказывают посещение настоящим поисковым роботом.

Первый запуск probe ошибочно сопоставил Python `None` отсутствующего заголовка со словом `none`; HTTP-ответы были успешны. Проверка исправлена на пустую строку при отсутствии заголовка и повторена. [Исходный результат](probe-first-result.json) сохранён; это ошибка проверочного скрипта, не сайта.
