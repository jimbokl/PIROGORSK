## Готовые импорты Astro

Для `src/pages/index.astro` (в компоненте непосредственно в `src/components/` тот же относительный префикс):

```astro
import { Picture } from 'astro:assets';
import heroBackground from '../../design/layered-assets-v2/hero/background.png';
import heroPie from '../../design/layered-assets-v2/hero/pie.png';
import companySlide from '../../design/assets-source/bundle.png';
import picnicSlide from '../../design/blog-source/unique-20261026/piknik-s-pirogom-chto-vzyat.png';
```

Оптимизация через существующий `Picture`: `formats={['avif','webp']}`, `fallbackFormat="webp"`; для picnic — `widths={[480,800,1200]}`, исходные `width={1536} height={1024}`, `quality={68}`, `sizes="(max-width: 760px) 100vw, 58vw"`. У bundle сохранять 1983×793; у прозрачного heroPie — квадрат. Первый видимый визуал загружать сразу; остальные слайды и нижние разделы — отложенно. Два hero-слоя считать одним суммарным весом.
