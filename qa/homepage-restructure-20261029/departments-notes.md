# Блок разделов главной

## Цель и границы

Короткая навигационная витрина для посетителя главной: быстро перейти к целым пирогам, мини-пирогам, десертам, хлебу, выпечке, первым идеям Пирогорска или дополнениям. Полный ассортимент остаётся в `/menu/`; компонент рендерит семь компактных иллюстраций и не размножает весь каталог.

## Источники

- Главная: вход из брендового поиска и прямых визитов; следующий шаг — выбрать раздел и открыть каталог.
- Существующие адреса menu: `#pirogi39`, `#holland`, `#menu-extras-title`, корень `/menu/`.
- Группы Holland Bakery: mini-pies, bread, desserts, bake, dough; подписи сверены с `src/data/holland-catalog.ts`.
- Число позиций берётся динамически из `catalog.length`, сейчас 153.
- На странице нет подтверждённых скидок/акций; раздел отображает настоящие категории без выдуманного промо.

## Реализация

`src/components/HomeDepartments.astro` — семь responsive-карточек, с существующими ProductVisual/SupplierArtwork, scoped CSS и ссылкой на весь каталог. Телефон использует две колонки. Hover/focus уважает reduced motion.

Root интегрирует компонент в `index.astro` и проверит anchors, реальный браузер на 320/390/1280px, сборку и страницу после интеграции.
