## Исправление SEO-08

В отчёте товарной разметки от 30 октября четыре ошибочных примера:
`/pirogi/myasnoy-pirog/`, `/pirogi/pirog-s-kapustoy/`,
`/pirogi/pirog-s-vishney/`, `/pirogi/pirog-s-tvorogom-i-malinoy/`.
У общего шаблона восьми первых пирогов оставался `Product` без `offers`,
`review` или `aggregateRating`. Другие 145 позиций уже используют `ItemPage`.

Все восемь переведены на `ItemPage` с собственным canonical `@id`, названием,
описанием и `primaryImageOfPage` с URL/размерами. Это соответствует странице
отдельной позиции текущего проекта. Предложения продажи и отзывы не добавлены.
Основания: [Google Product snippet](https://developers.google.com/search/docs/appearance/structured-data/product-snippet),
[Schema.org ItemPage](https://schema.org/ItemPage).

Проверка выпущенного HTML теперь охватывает все **153 ItemPage** и отвергает
возврат старого `Product`. На временной копии сборки прежний тип восстановлен:
валидатор завершился с ожидаемой ошибкой; оригинальная сборка не менялась.
[Отрицательная проверка](schema-negative.json).

Локально: Astro/TypeScript — 498 файлов, 0 ошибок и предупреждений; build —
254 HTML; SEO — 153 ItemPage / 249 sitemap URL / 72 376 ссылок; 53 Node-теста,
expansion, product-pages, совместимость Worker и registry strict — PASS.
