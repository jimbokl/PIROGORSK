# Ссылки и наборы Пирогорска · 01.11.2026

`navigation-reference.png` — imagegen-референс: три сценарных входа с пироговым
городом, тёплыми крышами, морем и понятным направлением перехода; ниже — набор
с ингредиентами в виде ссылок. Из верхней части подготовлены три небольших
оригинальных фрагмента `link-*.png` для реальных ссылок сайта. Надписи и элементы
управления на сайте остаются HTML, а не частью картинки.

`bundle-town.png` — отдельная imagegen-подложка: пироговый город, маяк, Балтика,
колосья по краям и светлая нижняя часть. Текущие изображения пирогов лежат
отдельным слоем поверх подложки. Все пять наборов сохраняют состав и цену.

Принципы промптов: собственная иллюстрация Пирогорска, тёплый золотистый хлеб,
navy/turquoise/ivory, чистая композиция, без чужих логотипов. Для подложки — без
надписей и продуктов в переднем плане, верхняя треть с городом, нижние две трети
со свободным пространством. Реализация использует адаптивные WebP и lazy loading.

По последнему поручению пользователя изменена подача ссылок и наборов, а не
каталог. Лента, категории, 153 SKU, форматы, цены, подборка и атрибуция сохранены.
Регрессия количества проверяет не только итоговую сумму, но и координаты/высоту
карточки, цены и кнопки при 1→2→99→1. Протокол: `qa/catalog-polish-20261101/`.
