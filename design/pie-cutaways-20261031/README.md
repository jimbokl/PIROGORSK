# Крупный срез начинки · 31.10.2026

REF-03 после разбора «Арфы»: второй ракурс шести собственных пирогов —
мясного, рыбного, капустного, сырного, яблочного с брусникой и вишнёвого.
В качестве референса использованы собственные слои `design/layered-assets-v2/`.
Все шесть изображений созданы встроенным imagegen; чужие фотографии
и тексты не копировались. Полные промпты, исходные пути и SHA-256 —
в [manifest.json](manifest.json). PNG с прозрачностью сохранены отдельно,
исходные файлы генерации не перемещались.

Один крупный треугольный кусок, золотистая корочка, начинка на переднем
плане, без подписей и лишних предметов. Манера реалистичной иллюстрации
согласована с целыми пирогами. Это визуализация собственных идей меню,
а не свидетельство готового производства или подтверждённой рецептуры.

`PieGallery.astro` использует изображения в карточках главной/меню и на
страницах товаров. «Срез»/«Пирог» — отдельная кнопка с touch-областью
не менее 44 px, доступная с клавиатуры. Ссылка на товар сохраняется.
Высота и ширина ракурса одинаковы; переключение не вызывает сдвиг карточки.

Astro создаёт WebP 160/280/480 px для каталога и 320/480/800 px для товара.
Источники находятся внутри `template`: браузер не загружает срезы до
нажатия. При ошибке сохраняется целое изображение и доступен повтор.
Без JavaScript остаётся исходное изображение и ссылка на товар.

Изображения просмотрены по отдельности. Проверки телефона и планшета,
загрузки, клавиатуры, ошибки сети и no-JS —
в [протоколе](../../qa/pie-cutaways-20261031/README.md).
