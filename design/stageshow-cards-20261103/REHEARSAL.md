# UX-20 · Rehearsal

Gold: `opposite-corners`, скопированный вместе с LICENSE в `gold/`.
Эталон запущен в собственном playground stageshow и снят через `film.mjs`
на 400/390 px с reduced motion. Проверены `gold-400.png` и `gold-390.png`.

Адаптация: вместо чат-окна — один крупный предметный сюжет, вместо мелкой
промо-подписи — настоящее название направления. Принципы gold: ясный главный
объект, короткий текст и достаточное свободное место. Для реальной навигации
пирог и название размещены последовательно; декоративная рамка приложения
не перенесена. Все элементы — Astro/HTML, без React/kit в клиентском коде.

Просмотрены local-home-390/768, local-article-390/1280, local-related-390
и local-home-focus-320: пироги и город читаются, заголовки целиком, стрелки
на одной линии, 320 px показывает следующую карточку и сохраняет весь фокус.
Hover увеличивает только картинку на 4% и сдвигает стрелку на 2 px; карточка
остаётся неподвижной. При reduced motion трансформации и переходы отключены.

`layout.mjs` stageshow без прокрутки дал inconclusive: карточки находились
ниже viewport, поддерживаемых видимых контейнеров не было. Повторная проверка
каноническим `auditLayout` после прокрутки реальной страницы: 390/1280,
2/3 padded containers, no-issues-detected. Это ограниченная проверка отступов,
не автоматическое одобрение внешнего вида. Частично видимая вторая карточка не открывалась полностью при Tab; небольшой
focusin-обработчик прокручивает ряд, проверены Tab и Shift+Tab. Нативные ссылки дополнительно
проверены собственным browser QA: 24 вида, Tab/Enter, скролл, no-JS и hover.

Не проверено: физическое устройство и Safari. Проверены Chrome responsive
viewport 320/390/768/1280 и фактически загруженные AVIF/WebP изображения.
Production-проверка записывается в QA README после выпуска.
