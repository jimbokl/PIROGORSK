# Карточки Пирогорска · stageshow

Gold: `opposite-corners` из benjitaylor/skills/stageshow. Оригинал скопирован
в `gold/` вместе с лицензией; эталонные кадры находятся в QA спринта.
Заимствованы иерархия одного главного объекта, читаемая подпись и осмысленный
кроп. Чат заменён предметной сценой Пирогорска, рамки приложения не нужны.

На сайте используются нативные Astro/HTML-карточки, а не растровые скриншоты
интерфейса: текст, ссылки и фокус остаются настоящими. React/kit не добавляются
в клиентскую сборку. Для сцен повторно используются одобренные иллюстрации
`editorial-cards-20261101` и `blog-source/reading-20261101/picnic.png`.
