# Выразительный дизайн и восьмой пирог

Задача: главная должна ощущаться живой балтийской пироговой; каталог — восемь полноценных вкусов. Предыдущая доработка `334a938` улучшила UI, но не дала ожидаемого движения.

- [x] Hero: отдельные слои, переключение рыбного / мясного / вишнёвого пирога, выразительный наборный заголовок и морская графика.
- [x] Движение: короткая вступительная сцена на hover/fine устройствах, смена вкуса по кнопке, параллакс мышью, последовательное появление карточек при прокрутке. Статика с первого кадра, reduced motion.
- [x] Восьмой вкус: курица и грибы; ImageGen cutout + фон, предварительные 590 / 1090 ₽. Товарная страница и единый каталог frontend/Worker.
- [x] Проверки: 320 / 390 / 1280, клавиатура, выбор вкуса / веса / города / подборки; check/build/SEO/tests/Worker.
- [x] Выпуск сайта и Worker, публичный PSI mobile/desktop (100/100), доказательства и документация.

Никакого автоперелистывания или бесконечного движения. На touch полный первый кадр сразу статичен. Вступление на точном указателе ≤ 1.2 с, дальнейшая анимация по действию и входу секции; скрытая вкладка и reduced motion учитываются. Заявки остаются анонимными.
