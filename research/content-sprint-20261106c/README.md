музея не использован: web fetch вернул 400 `Content length is too large`.
Не переносили это ограничение на другие источники. Цены, часы, реальные
посещения, медицинские обещания и доступность блюда из вороны не сочинялись.

Уникальная практическая часть — различение истории/вывески/позиции меню,
две таблицы, словарь, последовательность вопросов о составе и комплектности
семейного заказа. Советы редакционные. Обложка — иллюстрация; живая птица
находится за окном, не на тарелке. Две схемы рисуются из подписанного SVG.
