## Как использовать Excel

1. На листе **«Сравнение»** задать цену продажи, размер заказа, фактическую стоимость доставки и платёж клиента за доставку. Жёлтые клетки редактируются.
2. Для покупки готового пирога заменить публичную цену и скидку данными счёта. Начальный пример: [картофель и сыр, 850 г за 999 ₽](https://pirogi39.ru/osetinskij-pirog-s-kartofelem-i-syirom/), из ранее собранного прайса проекта. Скидка 10% — сообщение пользователя, её применение к конкретному товару требует подтверждения поставщика.
3. Для своей выпечки выбрать **K01** или **Q01**. На соответствующем листе заполнить точную закупочную массу в граммах и цену за кг из накладной. Стоимость считается по **брутто**, исходное нетто сохранено рядом. Если закупка в штуках/литрах, сначала получить эквивалентную цену за кг по фактической массе.
4. Уточнить отсутствующие ингредиенты и дозы. Для воды у киша при её отсутствии в окончательной рецептуре явно поставить 0 г. Для положительной массы нужна цена; нулевая масса даёт нулевую стоимость без выдуманной цены.
5. После пробной выпечки записать количество готовых изделий и массу остывшей партии без упаковки. Отметить «Рецептура проверена: Да». Незаполненные данные сохраняют статус «Нужны данные» и пустой результат.
6. Заполнить потери, труд/энергию и подвоз сырья. Сравнивать изделия одинакового состава и веса. Если нужна новая строка, предусмотрены свободные строки в пределах 7–22; для нового вида пирога шаблон нужно расширить.

Формулы: `сырьё партии = Σ(закупочная масса, г / 1000 × цена за кг)`; `сырьё изделия = сырьё партии / число изделий`. Добавка на списания равна `сырьё / (1 − доля списаний) − сырьё`. Подвоз, упаковка и труд задаются на проданный пирог; нормальные потери обработки уже учитываются в закладке брутто, их не нужно повторно вводить как списания.

Доставка учитывается **один раз на заказ**: `(курьер − платёж клиента за доставку) / пирогов в заказе`. Резерв применяется только к выручке за пироги. Для точного бюджета его нужно заменить собственной подтверждённой структурой расходов, в том числе учесть комиссии/налоги с доставки, если применимо.

«Вклад» в таблице — остаток после учтённых переменных расходов, **до аренды, постоянных расходов и инвестиций**. При исходных плановых параметрах 1500 ₽ продажи, 999 ₽ закупки, 10% скидки, 5 ₽ подвоза, 40 ₽ упаковки и 10% резерва получается **405,90 ₽ на пирог**; доставка 350 ₽ оплачивается клиентом полностью. Если её оплачиваем мы при заказе одного пирога, остаётся **55,90 ₽**. Это иллюстрация заданных допущений, не фактическая прибыль.

## Что делать дальше

Для текущего теста спроса использовать прайс готовых пирогов и реальные условия поставщика из [исследования поставщиков](../suppliers-20261029/README.md). Для изучения своей выпечки начать с картофеля/сыра и киша с фетой; после них проработать капустный K04 и зелёный Q07. Решение о платной базе принимать по числу рецептур и выбранной системе учёта, когда будет понятен объём собственной выпечки.

Чтобы получить фактическую себестоимость, остаются конкретные входные данные: закупочные цены ингредиентов и упаковки, точные граммовки, выход контрольной партии, труд/энергия, логистика и списания. Они не заменены случайными среднерыночными ценами.

## Проверка результата

Формулы проверены пересчётом в Artifact Tool: закупка со скидкой; доставка на два пирога; выбор рецептуры; стоимость тестовой партии; пустая цена; явный ноль; независимость двух моделей; некорректная сумма резерва и целевого вклада. Синтетические значения после проверки удалены. Ошибок формул при финальном поиске не найдено. Проверены изображения всех четырёх листов. Нативный пересчёт в Microsoft Excel отдельно не выполнялся.
