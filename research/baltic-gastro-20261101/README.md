# Балтийский гастро-ужин — материал для развития Пирогорска

Сохранено 01.11.2026. [Полный исходник](USER-CONCEPT.md) сохранён дословно;
[источник и контрольная сумма](source.json) записаны отдельно.

Материал содержит позиционирование доступного гастро-ужина, четыре идеи
пирогов («Куршский улов», «Кёнигсбергский пирог в стиле Клопс», «Золото
Балтики», «Прусский Раух»), дегустационный квартет, соусы и вкладыш-гид.
Рецептуры, цены, доли ингредиентов, food cost, происхождение сырья,
температуры и показатели поведения покупателей приведены как утверждения
автора исходника. Их проверка и расчёт не выполнялись; это не новые
характеристики опубликованных товаров.

Следующее возможное развитие — продуктовая матрица четырёх пирогов и
дегустационного сета с проверяемой калькуляцией. Запись GASTRO-01 в
[общем бэклоге](../../BACKLOG.md) связывает материал с дальнейшей работой.

Визуальное направление пользователь утвердил отдельно:
[айдентика текущего пикник-сета](../../design/BRAND-DIRECTION.md).
